# Autoridade e continuidade

GitHub dgsiria71-jpg/UNREAL-ENGINE-FUTEBOL, main, é a linha oficial de incrementos publicados. Trabalhar localmente em Git e publicar após validação. Nunca fazer force-push para substituir histórico remoto.

Correções diretas mais recentes do proprietário prevalecem. A Bíblia v3 em Docs/Bible_v3 define o produto e o escopo; checkpoints e evidência executável atual corrigem afirmações técnicas antigas. Documentação inicial do GitHub foi preservada, mas seus estados históricos não anulam recuperação já testada.

Leia integralmente Bíblia, Quickstart, Source Policy e manifesto, depois CURRENT/EVIDENCE e os contratos do subsistema. Unity é fonte mobile; Unreal/C++ é o destino. Neymar pausado. Downloads/Videos são as áreas de descoberta de novas fontes. 1-226-19 não pertence à linha atual.

Fluxo: inspecionar Git/checkpoint -> implementar sem recomeçar -> testar -> registrar limites/evidência -> commit -> publicação no GitHub -> confirmar SHA remoto.
