# PERFORMANCE TARGETS

Primary target: 120 FPS (~8.33 ms/frame) on the defined reference PC during a REAL match, not an empty field/menu. Profile Game Thread, Render Thread, GPU, Physics/Ball, Animation, Player AI, Team AI, Networking, Crowd, UI, Memory and VRAM.

Support Low/Medium/High/Ultra graphics while preserving logical simulation. Do not couple football behavior to render FPS; use suitable fixed/substepped simulation and render interpolation where needed. AI should use frequency tiers and relevance without destroying team shape.
